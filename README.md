# 👜 EcoTote

**Responsive landing page** for an eco-friendly bag brand with basic backend interaction.

---

## 🚀 Live Demo

👉 https://diamond-foxua.github.io/ecotote/

---

## 📌 About the Project

EcoTote is a responsive landing page designed to showcase eco-friendly tote bags and promote sustainable lifestyle values.  
In addition to static content, the project includes **interaction with a backend API**, allowing users to fetch and view available books from the backend.

The project was developed as part of a **team project**, focusing on collaboration, layout structure, and frontend fundamentals.

---

## 🧩 Key Features

✔️ Responsive layout (mobile, tablet, desktop)  
✔️ Semantic HTML structure  
✔️ Clean and consistent UI  
✔️ Smooth navigation between sections  
✔️ **Fetching data from backend API (view available books)**  
✔️ Optimized assets for fast loading  

---

## 🛠️ Technologies Used

- **HTML5** — semantic markup  
- **CSS3** — Flexbox, responsive styles  
- **JavaScript** — DOM manipulation and API interaction
